# 租房合同与约定要点

平台当前以「房源信息 + 租房订单 + 缴费记录」作为租房约定的载体，电子合同签署功能在规划中，尚未上线。线下签署合同时，建议重点确认以下条款：

1. **租期**：起止日期、是否可续租、提前退租的违约责任。
2. **租金与押金**：金额、支付周期、押金退还条件与时限。
3. **费用承担**：水电燃气、物业、网络、维修费用由谁承担。
4. **维修责任**：自然损耗与人为损坏的区分，报修响应时限。
5. **转租与合租**：是否允许转租、合租人数限制。
6. **物品清单**：入住时的家具家电清单与状态，最好拍照留档。
7. **退租条款**：提前通知天数、清洁费/损坏赔偿的计算方式。
8. **违约条款**：双方违约的具体情形与赔偿标准。

建议：

- 合同中的出租方应与房源发布房东一致；如为二房东，要求出示授权或原合同。
- 所有付款尽量走平台钱包或可留痕的转账方式，避免现金。
- 对口头承诺（如「住满一年退全部押金」）要求写进合同或聊天记录。
- 平台内聊天记录可作为纠纷处理的辅助证据。
