# 预约看房规则

- 预约看房需要先登录租客账号，并填写看房时间与联系方式。
- 同一租客对同一房源不能重复发起未完成的预约。
- 房东可以在管理端**确认 / 完成 / 取消**预约；租客也可以在预约列表中取消自己的预约。
- 只有房东把预约标记为「已看房」后，租客才能基于该预约**确认租房**；这是为了防止「没看房就下单」。
- 看房时间以双方约定为准；如需改期，建议先在聊天中沟通，再取消/重新预约。
- 若房东长时间不处理预约，可以换其他房源或联系房东；平台不会强制派单。
- 看房时建议核实房源与房东身份，不要在看房阶段向个人账户支付大额定金。
