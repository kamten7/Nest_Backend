# 租房防诈骗提示

请警惕以下常见套路：

1. **低价引流**：房源图片精美、价格明显低于市场价，要求先交「诚意金/看房费」才给看房。
2. **冒充房东**：无法出示房产证/授权书，或要求把租金转到与房东姓名不一致的账户。
3. **假合同**：合同主体与收款人不一致，或关键条款留白。
4. **催转账**：以「房子很抢手」「今天不定就没了」为由催促私下转账。
5. **扫码/链接**：发送陌生二维码或链接要求「验证身份/交保证金」。

安全做法：

- 优先在平台内预约、沟通、下单与缴费，资金流水可追溯。
- 看房时核实房东身份与房源信息；二房东要求出示授权。
- 不向陌生人透露身份证、银行卡、短信验证码。
- 任何「先交钱再看房」「转到个人微信/支付宝」的要求都要高度警惕。
- 发现可疑房源或账号，及时在平台举报并保留证据。
