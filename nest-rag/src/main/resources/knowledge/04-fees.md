# 费用说明

租房涉及的费用通常包括：

| 费用 | 说明 |
|------|------|
| 租金 | 按自然月计算，具体金额以房源详情页为准 |
| 押金 | 通常为一个月租金，退租结算后按规则退回 |
| 水电燃气 | 按实际使用量结算，通常由租客承担，以房源详情或合同约定为准 |
| 物业费 | 由房东或租客承担以房源约定为准；平台不代收 |
| 网络/宽带 | 部分房源标注「包网费」，以房源标签与描述为准 |
| 中介费 | 平台为房东直租模式，不收取中介费；如遇他人索要中介费请谨慎核实 |

注意事项：

- 平台钱包只用于租金、押金、提现等平台内资金流转，**不代收水电物业**。
- 任何要求向个人账户私下转账「定金/看房费」的行为都存在诈骗风险，请先核实房东身份。
- 费用以房源详情页、订单页与双方约定为准；如发现房源描述与实际收费不一致，建议保留证据并联系平台处理。
