# 租金与缴租规则

## 起租与待缴周期

- 租客缴纳押金成功后，订单进入「租房中」，系统写入起租日和首个待缴周期（yyyy-MM）。
- 租金按自然月计算，逐月缴纳；订单详情页会显示当前待缴周期与缴费记录。

## 提前支付

- 支持提前支付未来 **1–5 个月** 的租金，一次扣款、生成多条缴费记录，并共享同一个业务批次号。
- 提前支付的月份会计入房东的「锁定金额」，在退租时未消耗的部分会退回租客。

## 缴租提醒

- 系统在缴租日到期前 **3 天** 自动提醒租客（站内通知 / 长连接推送）。
- 提醒按「订单 + 待缴周期 + 日期」去重，不会重复轰炸。

## 逾期与重复支付

- 同一订单、同一缴费周期只能成功缴纳一次，数据库唯一键会挡住重复支付。
- 如果支付时提示「缴费周期与订单待缴周期不一致」，通常是页面数据过期，刷新订单详情后再试。
- 平台当前使用钱包余额支付；真实微信支付尚未接入，`demo` 环境提供模拟充值，仅用于本地演示。
