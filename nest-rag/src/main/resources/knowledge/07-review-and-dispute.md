# 评价、回复与纠纷处理

## 评价规则

- 只有**租过该房源**的租客可以发表评价；房源已下架时，租过该房的租客仍可回来评价。
- 评价支持 1–5 分评分与文字内容；可以删除自己发表的评价。
- 评价支持点赞、房东/租客回复，回复支持嵌套追问。
- 同一用户对同一评价/回复只能点赞一次，重复点击是「取消点赞」。

## 纠纷处理建议

1. **先沟通**：通过平台聊天与房东沟通，保留聊天记录。
2. **留证据**：房源照片、缴费记录、合同、聊天记录、维修单据。
3. **按订单规则处理**：押金与预付租金按退租结算规则退回；有损坏赔偿的，房东需说明合理依据。
4. **平台介入**：协商不成的，联系平台客服，提供订单号与证据。
5. **警惕线下私了**：不要在没有书面确认的情况下接受「先转账再退押金」等方案。

平台的目标是把「房源信息、预约、订单、资金流水」都留痕，方便双方对账；但平台不是执法机构，最终以合同与证据为准。
